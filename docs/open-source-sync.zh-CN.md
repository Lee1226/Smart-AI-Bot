# 本次通用功能同步

支持鸿蒙 HDC 接入、平台对应应用标识、项目归属、加密测试账号（手机号与验证码、邮箱与密码）、设备调度、多设备回归和 CI 门禁。项目知识库和源码仍为本机配置，不包含任何业务内容。

## 首次使用

启动后在网页注册首个工作区账号。旧版无归属的设备和用例归入首个工作区；后续公开注册默认关闭。平台设置及项目测试账号仅供实例管理员使用。配置模型凭据后，在设置中建立项目和账号，运行时选择对应账号。

知识库 CLI 默认没有允许命令。如需启用，服务启动时显式设置 `SAB_KB_SEARCH_COMMAND_ALLOWLIST`，例如 `kb-search`，项目中再填写该命令。服务权限仅允许可信管理员配置本地路径和检索命令。

账号和验证码加密存储在数据目录，密钥权限为 0600；文字日志脱敏，但截图、录屏和诊断日志可能含应用数据，分享前需检查。普通短信验证码过期后需更新，程序不读取短信。

APK 上传和安装仅对已认证用户开放；下载使用短期运行授权。清除应用数据需在回归计划中显式选择。鸿蒙当前不支持 Android APK 安装。

本次同步不包含内部 SSO、内部网关、专用客户端发布、业务知识库、实际账号、数据库、密钥、本机路径或设备配置。

## Android 与 iOS/Mac 配套补齐

- Android 客户端补齐真正的系统设置强停、真机操作事件录制、远程 H.264 视频服务及录屏授权入口。强停依赖无障碍服务与系统设置页面；系统版本差异仍需真机验收，失败会明确返回错误。
- 多平台截图不再重复缩小；模型坐标按实际图片尺寸映射回设备，并正确标记 PNG/JPEG。
- iOS 提供 USB WDA 桥接、本机显式启用的直连方式、五分钟一次性配对码、账号隔离的远程 Mac 助手及撤销连接。Mac 原生助手统一发现 Android、鸿蒙和 iOS，使用独立权限为 0600 的配置；不预填任何组织服务地址。
- Mac 源码、构建脚本与下载接口均公开。构建出的 `.app`、zip、签名凭据、WDA 产物与设备配置不提交；正式分发需自己的 Developer ID 和 Apple 公证。发布源码不等于已有可下载的正式安装包。
- [Maestro 用例包管理](automation-catalog.zh-CN.md)保留独立的上传、版本、依赖、截图与下载能力，使用公开版 `.sabcase` / `.sabplan` ZIP 格式，不连接专用客户端商店，不执行上传的 YAML。
- 仓库根目录的 `cli/sab` 支持设备查询、安装、套件、任务和结果轮询；Docker 构建包含脚本与下载用的桥接源码。CLI 配置权限为 0600，默认列出配置时隐藏 API Key。

公开版继续保留文字日志与测试凭据脱敏、账号权限隔离、空知识库命令允许列表及通用模型服务默认值。不会原样复制内部版取消脱敏的差异或任何内部登录、网关、专用发布服务及业务内容。

## 验证边界

协议及接口测试使用临时数据库、模拟设备和公开示例，不连接内部服务。浏览器检查只证明本机测试实例的页面与相应交互；不能替代 Android 强停、真机录制/视频以及 iPad WDA 的设备验收。构建、安装、页面检查、真实业务验收和部署发布应分别记录。
