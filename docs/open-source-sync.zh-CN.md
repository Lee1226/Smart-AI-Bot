# 本次通用功能同步

支持鸿蒙 HDC 接入、平台对应应用标识、项目归属、加密测试账号（手机号与验证码、邮箱与密码）、设备调度、多设备回归和 CI 门禁。项目知识库和源码仍为本机配置，不包含任何业务内容。

## 首次使用

启动后在网页注册首个工作区账号。旧版无归属的设备和用例归入首个工作区；后续公开注册默认关闭。平台设置及项目测试账号仅供实例管理员使用。配置模型凭据后，在设置中建立项目和账号，运行时选择对应账号。

知识库 CLI 默认没有允许命令。如需启用，服务启动时显式设置 `SAB_KB_SEARCH_COMMAND_ALLOWLIST`，例如 `kb-search`，项目中再填写该命令。服务权限仅允许可信管理员配置本地路径和检索命令。

账号和验证码加密存储在数据目录，密钥权限为 0600；文字日志脱敏，但截图、录屏和诊断日志可能含应用数据，分享前需检查。普通短信验证码过期后需更新，程序不读取短信。

APK 上传和安装仅对已认证用户开放；下载使用短期运行授权。清除应用数据需在回归计划中显式选择。鸿蒙当前不支持 Android APK 安装。

本次同步不包含内部 SSO、内部网关、专用客户端发布、业务知识库、实际账号、数据库、密钥、本机路径或设备配置。
