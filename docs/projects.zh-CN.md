# 项目与多平台用例

一个业务项目关联一份知识库，并分别配置 Android 包名、鸿蒙 Bundle Name、iOS Bundle ID。应用标识用于启动和停止应用，知识库使用项目 ID 关联；检索仍按运行设备的平台筛选。

## 使用

1. 在「设置 → 项目档案」创建项目，配置知识库路径或检索命令。
2. 填写项目支持的平台应用标识，暂不支持的平台可以留空。
3. 在测试套件页选择「所属项目」，套件中的用例和步骤继承这个归属。
4. 选择设备执行；系统按设备平台取应用标识。未配置当前平台或项目已删除时，运行前提示补充配置。
5. 快速任务也可以选择所属项目。

旧配置的 app_package 兼容为 Android 标识。启动服务时，已有匹配包名的套件自动关联原项目，不复制知识库。未关联项目的旧版包名仅用于 Android；多平台应选择项目。

项目档案仍属于本机运维账号配置，不向其他账号暴露本地知识库或源码路径。新增项目归属不会改变现有账号隔离。

API: 项目增加 `app_ids`，例如 `{"android":"com.example.app","harmony":"com.example.harmony"}`；套件和快速任务增加 `project_id`。套件 PATCH 提交 `{"project_id":"项目ID"}`，空字符串取消显式归属。旧套件的包名匹配仍兼容保留。

此版本只配置 iOS 应用标识，不新增 iOS 设备执行能力。

## 测试账号

在项目档案下添加测试账号，配置账号名称、环境、适用平台、登录方式、登录账号和密码。一个项目可设置一个默认账号；编辑时登录账号和密码留空代表保留原值。删除会清除登录信息，历史运行仍保留账号名称。

套件或快速任务运行时，可使用项目默认账号、选择其他账号，或选择「不使用测试账号」。用例只写角色和前置条件，例如「使用超级用户测试账号登录」，不用把手机号和密码写进用例或知识库。当前版本不自动从用例角色名称推断账号，执行前应选择对应角色。

AI 先观察是否已登录；无法确认身份时不能直接认定匹配。需要登录时通过 `input_test_credential` 填写当前选定账号；凭据在本地解密和输入，工具返回不包含明文。支持手机号验证码登录、邮箱密码登录，以及可选的密码登录。AI 根据登录方式选择对应入口，邮箱不填写到手机号输入框。手机号账号可配置验证码，AI 在本地填写手机号和验证码；支持测试环境固定验证码，普通短信验证码过期后需更新，不自动获取短信。已移除人工登录选项，旧配置需编辑并保存为实际登录方式。当前不支持凭据填写步骤的确定性回放。

同一账号被待执行或运行任务占用时，不允许再次使用或编辑。账号的环境是说明字段，当前不会切换 App 的服务器环境，也不能据此验证 App 实际连的是哪个环境。

登录账号和密码采用 Fernet 加密，密钥默认位于数据目录 `.test_account_key`（0600）。部署迁移需安全保留数据库和密钥；不要把密钥提交到仓库。可通过 `SAB_TEST_ACCOUNT_KEY_PATH` 指定密钥路径。

接口只返回脱敏账号和密码是否配置；文字日志、工具记录和结果中的所选凭据会脱敏。设备屏幕上的手机号等信息仍可能出现在实时画面、截图和录屏中，当前没有图像脱敏。说明字段不要写其他敏感信息。

项目账号仍受本机运维账号隔离，不与 SAB 登录账号混淆。
