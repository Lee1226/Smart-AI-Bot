# SAB 浏览器 USB 本地模式（试用版）

在设备页选择「连接 USB 手机」，选择手机，并在手机上允许 USB 调试。无需安装 SAB Portal 辅助 App；被测 App 仍需已安装在手机上。需要桌面 Chrome/Edge，以及 HTTPS 或 localhost 地址。普通局域网 HTTP 地址不能使用 WebUSB。

## 设计

```text
现有模式：SAB AI / 测试运行器 → WebSocket → Portal App → 手机
本地模式：SAB AI / 测试运行器 → WebSocket → 当前网页 → WebUSB / ADB → 手机
```

两种模式共用套件、快速任务、AI 分析和报告。本地指手机执行端在用户电脑；AI 仍由 SAB 服务端执行，不是离线 AI。网页不运行官方 Android CLI 或 Journeys 二进制，使用 Tango / @yume-chan 的 JavaScript ADB 实现。

设备记录增加 `connection_type`：旧设备默认 `portal`，新模式为 `browser_usb`。浏览器通过 `/v1/providers/browser-usb` 首帧发送设备 token，服务端确认类型后返回 ready，再复用原有 RPC。token 不放在 WebSocket URL。设备 token 是执行端凭据，勿分享；开源版沿用现有部署的访问方式，请仅向可信用户开放服务。

连接属于当前标签页：切换 SAB 页面可继续运行，关闭、刷新、退出登录、断开 USB 或服务端连接后需要重新连接。一个标签页同时连接一台手机；同一本地设备记录拒绝重复执行端。重新连接已有记录时，在该记录上点击「连接 USB」，并确认选择的是对应手机。

## 支持范围

| 能力 | 本地模式 |
| --- | --- |
| 截图 / 实时预览 | PNG 截图；当前 USB 标签页的「自动」模式通过 WebUSB 直接接收 H.264 录屏并本地播放，失败回落截图；测试过程跳过服务端 ADB 录屏 |
| UI 树 / 当前包名 | UIAutomator XML，原生屏幕坐标；WebView/游戏节点可能不完整 |
| 点击、滑动、按键 | ADB input |
| 启动、停止、列出 App / 通知栏 | Android shell 命令 |
| 文本输入 | 可打印 ASCII，暂不支持 %、中文和自动清空 |
| APK URL 安装、录像保存、音频 | 暂不支持，RPC 明确报错；请使用现有 App 模式。实时录屏仅供预览，不保存录像 |
| AI 测试 / 套件 / 报告 | 复用 SAB；具体任务须满足上述能力范围；AI 提示会告知本地能力限制 |

截图按现有 SAB 协议缩小到原生尺寸的 50%，保持 AI 坐标与后端两倍换算一致。UI 树坐标仍是原生坐标。每个设备操作串行执行，RPC 从到达开始限制 25 秒，单条 shell 操作也限制 25 秒，排队超过 20 秒不再执行，以减少过期点击。状态获取可能因动画持续运行导致 UIAutomator 超时。

## 使用与排障

1. 开启手机开发者选项、USB 调试，USB 接入电脑并解锁。
2. 登录 SAB，设备页连接 USB；手机确认来自「SAB Browser USB」的调试授权。
3. 在线后先用系统设置做简单截图和按键验证，再选择该设备执行快速任务或套件。保持标签页打开，不建议后台长时间运行，浏览器休眠会影响执行。
4. 如果提示 USB 被占用，关闭使用设备的 Android Studio 等工具，或手动执行 `adb kill-server` 后重试；结束后可运行 `adb start-server` 恢复本机工具。不自动停止用户其他 ADB 会话。
5. 小米等设备可能还需要开启「USB 调试（安全设置）」才能执行点击/输入；缺少权限时应检查返回错误及实际手机反应。

ADB 私钥由库保存在当前浏览器的 IndexedDB，授权按浏览器来源隔离。不要把整个 SAB 页面嵌入不可信站点。不要同时从其他工具操作同一手机，否则截图和动作可能互相干扰。

### USB 实时画面

连接 USB 后，在同一标签页的设备页或运行详情页，将「实时画面」切到「自动」。手机的 `screenrecord` 输出 H.264，通过独立的 WebUSB ADB shell 通道直接交给浏览器播放器；不经过 SAB 服务端，也不占用 AI 操作队列。优先使用 WebCodecs Canvas，缺少 WebCodecs 时使用 MSE 播放器。

录屏约每 175 秒重启一次并重置播放器，重启期间可能有短暂停顿。停止预览、切换设备、页面卸载或 USB 断开会关闭录屏通道。录屏启动失败或启动后 15 秒内没有视频数据时自动回落截图；再次点「自动」重试。其他标签页可以查看截图，但不能直接播放本标签页的 USB 视频。截图仍用于 AI 分析，视频预览不改变 AI 坐标或执行链路。安全页面的黑屏属于 Android 录屏限制。

## 验证边界

后端协议测试只验证身份、设备类型隔离、RPC 成功/错误、重复连接、断开清理和预览不误用服务端手机。构建和页面验证不代表实际 WebUSB 手机验收，必须另外确认选设备、手机授权、实际截图、点击/按键和 SAB 任务结果。
